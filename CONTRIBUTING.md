\# Contributing



\## Правила участия в проекте



1\. Все изменения должны выполняться в отдельной ветке.

2\. Перед началом работы необходимо получить актуальную версию репозитория.

3\. Название ветки должно отражать характер изменений.

4\. Коммиты должны содержать понятное описание внесённых изменений.

5\. Изменения в ветку `main` вносятся через Pull Request.

6\. Перед созданием Pull Request необходимо проверить внесённые изменения.

7\. После завершения работы использованная ветка удаляется.
